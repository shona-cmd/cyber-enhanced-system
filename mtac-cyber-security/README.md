# Naashon Secure IoT - Demonstration Instructions

To demonstrate this software locally on all devices, follow these steps:

1.  Ensure all devices are connected to the same local network.
2.  Open a terminal in the project directory (`d:/cyber-enhanced-system-1/mtac-cyber-security`).
3.  Run the command `npm run dev`. This will start the development server.
4.  Take note of the IP address that Vite displays in the terminal (e.g., `192.168.1.100`).
5.  On other devices, open a web browser and navigate to `http://[IP address]:5173`, replacing `[IP address]` with the IP address noted in the previous step. If port 5173 is not correct, use the port number that Vite displays in the terminal.

This will allow you to access the application from any device on the local network.
